# Crowdamp

Crowdamp is a privately held Lightspeed Venture Partners portfolio company co-founded by Ruben Mayer-Hirshfeld and Alexandra Botez. The company built SuperFan, a creator-economy messaging product that let fans text their favorite social media stars and receive a personalized reply, using natural language processing to help those creators respond efficiently at scale.

Backed by: lightspeed-venture-partners

## API surface

None. The July 2026 enrichment pass found no developer portal, documentation, API reference, specification, SDK packages, or public developer surface of any kind.

- Product domain `superfanapp.com` (and `api.` / `docs.` subdomains) redirects to a HugeDomains for-sale listing — the product site is no longer live.
- `crowdamp.com` is an unrelated parked domain on ParkingCrew nameservers.
- No `crowdamp` package on npm or PyPI.
- `/.well-known/` probes returned the reseller parking page, not real documents.
- A dormant `github.com/CrowdAmp` organization exists (2016, last push 2016) but nothing ties it to this company, so it is not claimed here.

This repository is retained as a portfolio-graph record rather than as an API provider profile.
